## 슬라이드 선택

- 핵심 기능 소개: **01**
- 실제 NASA 지형과 분석 기능: **02–04**
- 탐색 사용자 경험: **05**
- 장애물 추가와 적응형 재계산 전후: **06 → 07 → 08**

05를 캡처한 뒤 WASD로 약 2.4m 이동했습니다. 06–08은 그 현재 위치에서
진행한 장애물 재계산 장면입니다. 따라서 01의 전체 경로 길이와 07의 새 경로
길이를 같은 출발점의 전후 비교로 설명하지 마세요. 정확한 전후 비교는
07 상단의 **713.5m → 753.7m**입니다.

위성 영상과 지형은 실제 HiRISE 데이터이며, 위치·보행·장애물은 시뮬레이션입니다.
낮은 위험도는 정의된 비용 함수의 명칭이며 실제 안전 인증을 의미하지 않습니다.
NASA/PDS 원본 정보는 앱 우측 Data provenance에 표시됩니다.

이번 캡처에서 표시 모드 전환, 카메라 회전·확대, 1인칭 모드 진입과 WASD 이동,
장애물 배치·윤곽선, GPU 경로 갱신 및 재계산 후 탐색 복귀를 실제 화면으로 확인했습니다.
